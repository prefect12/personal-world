# Kade Wu — Choose your world

[打开网站](https://prefect12.github.io/personal-world/)

## 三个入口

- **Ocean**：海报首页 → 进入海岛 → 驾驶小船探索 8 个简历地点。
- **Orbit**：太空海报 → 进入宇宙 → 驾驶飞船访问对应星球。
- **Journey**：以滚动视差、固定阶段内的横向经历推进、逐段揭示和动态技术图形阅读个人经历。

首页菜单切换海报，点击进入后才加载对应内容。Studio 已被 Journey 替换。

## 游戏操作

WASD / 方向键移动，Shift 加速；手机提供方向按钮。靠近岛屿或星球后点击阅读按钮，也可点击场景中的名称。地图上的 1–8 对应八个地点，点击可快速前往。支持视野缩放、返回港口、暂停环境动画；阅读进度保存在本机 localStorage。

探索区域为 X -48 至 44、Z -40 至 44；相比第一版面积约为 11.4 倍。场景包含不同建筑、礁石、海豚、海鸟、旋转地标、星球和 12 个可收集航标。

## 本地运行

```sh
python3 -m http.server 8937 --bind 127.0.0.1
```

通过 `http://127.0.0.1:8937/` 访问。无需构建；ES modules 需要 HTTP，不能通过双击 HTML 的 file URL 运行。

```sh
npm run check
```

`content.js` 管理资料和地点，`main.js` 管理入口与弹窗，`worlds.js` 管理 3D 世界，`journey.js` 管理滚动行为。Three.js 0.180.0 已保存在 vendor 目录，其 MIT 许可证见 `vendor/THREE-LICENSE.txt`。浏览器不依赖外部 CDN。

## 图片与验证

海岛与太空海报由第一版生成概念图编辑为无文字背景；Journey 使用独立生成的橙色缎带素材。正式素材位于 `assets/`，三个 WebP 总计约 570 KB，菜单与文字均为真实 HTML。

在 Codex 内置浏览器验证桌面和 390×844 手机模拟视口：海报切换、菜单、延迟加载游戏、键盘/触控移动、相机跟随、地图定位、简历弹窗、阅读记录和 Journey 滚动推进。未发现控制台错误。游戏为实时低多边形模型；海报是写实风格图片，两者视觉细节不同。真实手机硬件及其他浏览器尚未单独测试。
